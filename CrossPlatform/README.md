# Aplicación de escritorio

Windows y macOS comparten código, interfaz, recursos y comportamiento. Solo varían la integración del sistema y el perfil de dependencias. La versión web vive en `Web/` y usa HTML, CSS y JavaScript.

Para preparar un entorno, ejecutar y compilar la aplicación, consulta [la guía de compilación](../docs/BUILDING.md). Los recursos y avisos de terceros están descritos en [CREDITS.md](../CREDITS.md) y [docs/legal](../docs/legal/).
