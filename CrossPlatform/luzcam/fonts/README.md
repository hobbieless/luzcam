# Tipografía compartida

Noto Sans, Noto Serif y Noto Sans Mono se cargan desde estos archivos en ambos
sistemas. No se eligen las fuentes nativas de Windows o macOS para los textos
de la interfaz. Se incluyen los tres avisos SIL Open Font License 1.1.

Origen: https://github.com/google/fonts/tree/main/ofl/notosans,
https://github.com/google/fonts/tree/main/ofl/notoserif y
https://github.com/google/fonts/tree/main/ofl/notosansmono.

Descargadas el 11 de noviembre de 2026; estos archivos versionados son la
referencia reproducible. Los iconos de la interfaz se dibujan con Qt.
