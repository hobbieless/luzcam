# Privacidad

LuzCam no requiere una cuenta y no incorpora telemetría. La aplicación no necesita acceso a la cámara, el micrófono ni la biblioteca de fotografías del dispositivo.

Las capturas didácticas se calculan localmente y se conservan en memoria durante la sesión, hasta un máximo de 100. No se sustituyen ni se eliminan automáticamente; vaciar el carrete requiere una acción explícita. Al cerrar la aplicación, esas capturas de sesión dejan de estar disponibles.

La aplicación de escritorio puede guardar preferencias locales de idioma y presentación. También puede escribir un registro local de errores para facilitar el diagnóstico. Ese archivo puede incluir mensajes de error y rutas del equipo; revísalo antes de compartirlo.

La versión web almacena los recursos visitados en la caché del navegador para permitir su uso sin conexión después de la primera visita. Las capturas de la sesión no se envían a un servidor.
