# LuzCam

**Un laboratorio visual para entender cómo se hace una fotografía.** Ajusta apertura, velocidad y sensibilidad; sigue la luz por la cámara y observa cómo cambia la imagen.

LuzCam es un proyecto educativo gratuito de Hobbieless, creado por César González. Ofrece un simulador para navegador y una aplicación de escritorio con la misma experiencia para Windows y macOS.

## Probar

- **Aplicación web:** [abrir LuzCam](https://hobbieless.com/luzcam/app/)
- **Windows:** [Microsoft Store](https://apps.microsoft.com/detail/9NWDHHBSV5K9)
- **Información del proyecto:** [hobbieless.com/luzcam](https://hobbieless.com/luzcam/)
- **macOS:** todavía no hay una descarga pública.

La simulación es didáctica: las mediciones ópticas y algunos efectos de imagen son aproximaciones.

## English

**A visual lab for learning how a photograph is made.** Adjust aperture, shutter speed and sensitivity, follow light through the camera, and see how the image changes.

LuzCam is a free educational project by Hobbieless, created by César González. It offers a browser simulator and a desktop application with the same experience for Windows and macOS.

- **Web app:** [open LuzCam](https://hobbieless.com/luzcam/app/)
- **Windows:** [Microsoft Store](https://apps.microsoft.com/detail/9NWDHHBSV5K9)
- **Project information:** [hobbieless.com/luzcam](https://hobbieless.com/luzcam/)
- **macOS:** no public download is available yet.

The simulation is educational; optical measurements and some image effects are approximations. The original code is licensed under **GNU GPL v3.0**. Artwork, fonts and dependencies retain their own terms and credits. CameraSim and Canon Outside of Auto were consulted only as educational inspiration; LuzCam is independently implemented and is not affiliated with or endorsed by them.
